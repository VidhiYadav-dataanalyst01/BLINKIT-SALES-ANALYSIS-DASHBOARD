# Interactive Blinkit Sales Analysis Dashboard
## Project Overview
Developed an interactive Power BI dashboard to analyze Blinkit's sales performance, customer preferences, and outlet performance. The dashboard provides actionable insights into sales trends, product categories, outlet types, and customer ratings to support data-driven business decisions.

## Business Objective
The objective of this project was to analyze Blinkit's sales data and identify key factors influencing sales performance, customer satisfaction, and outlet efficiency.

## Dataset Information
The dataset contains information related to:
- Item Fat Content
- Item Identifier
- Item Type
- Item Weight
- Item Visibility
- Outlet Identifier
- Outlet Establishment Year
- Outlet Size
- Outlet Location Type
- Outlet Type
- Sales
- Ratings

## Key Performance Indicators (KPIs)
- Total Sales
- Average Sales
- Total Number of Items Sold
- Average Rating

## Dashboard Features
### Sales Analysis
- Total sales by item type
- Total sales by outlet type
- Total sales by outlet location
- Total sales by fat content

### Outlet Performance Analysis
- Sales by outlet size
- Sales by outlet establishment year
- Performance comparison across outlet types

### Customer Insights
- Average ratings across outlets
- Product category performance analysis

## Visualizations Used
- KPI Cards
- Donut Chart
- Clustered Bar Chart
- Funnel Chart
- Line Chart
- Matrix Table
- Slicers for interactive filtering

## Key Insights
- Supermarket Type 1 generated the highest overall sales among all outlet types.
- Tier 3 outlets contributed the highest sales revenue.
- Tier 1 outlets recorded the lowest sales performance.
- Certain product categories significantly outperformed others in terms of revenue generation.
- Customer ratings remained relatively stable across most outlet categories.

## Tools & Technologies
- Power BI
- Power Query
- Microsoft Excel
- DAX
- Data Cleaning and Transformation

## Business Recommendations
- Expand operations in high-performing Tier 3 locations.
- Investigate factors affecting lower sales in Tier 1 outlets.
- Increase inventory for top-performing product categories.
- Focus marketing efforts on high-revenue outlet types.
- Monitor customer ratings to maintain service quality.

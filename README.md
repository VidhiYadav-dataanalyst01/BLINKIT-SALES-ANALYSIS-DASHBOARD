# Interactive Blinkit Sales Analysis Dashboard
Built 2 interactive Power BI dashboards analyzing Blinkit sales dataset with 8k+ listings across 12 attributes to 
conduct a comprehensive analysis of Blinkit's sales performance, customer satisfaction, and inventory 
distribution and to identify key insights and opportunities for optimization using various KPIs and 
visualizations in Power BI. 
- Cleaned and transformed raw sales data using Power Query to improve data quality and consistency. 
- Created DAX measures and calculated columns to track KPIs such as Total sales, Average sales, Number of 
Items, Average rating. 
- Designed dynamic dashboards with slicers, filters and drill-down visualizations to enable interactive data 
exploration. 
- Identified Total Sales by Fat Content, Total Sales by Item Type,  Fat Content by Outlet for Total Sales, 
Total Sales by Outlet Establishment, Percentage of Sales by Outlet Size,  Sales by Outlet Location,  All 
Metrics by Outlet Type to generate business insights for decision-making.
